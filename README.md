# Internet Speed Test

Estimates your download speed in the browser, in plain HTML, CSS and JavaScript.

<img alt="Internet Speed Test" src="screenshot.png" />

The page downloads three large random photos from [Picsum](https://picsum.photos), one after another. For each one it counts the bytes that actually arrived and divides them by the time the download took, then shows the average in bits, kilobits and megabits per second.

Open `index.html` in a browser to use it; there is nothing to install.
